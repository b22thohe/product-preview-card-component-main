### What I learned

I got some more practice with flex-box and have a better understanding now of how flexbox works within other elements and how they might influence each other.

The major learning point was diving head-first into Sass. Still don't grasp all the basic concepts fully, but I found it relatively easy to get started with. 
I found that I very much prefer the SCSS syntax to Sass.

### Continued development

I need more hands-on practice with Sass/SCSS as well as read more on the subject. This was the first time I've tried anything Sass and I feel I learned quite a
bit working on this small project. But I still haven't used mixins and I'm still not comfortable enough with the file system and "what type of code goes in 
which file". But I can already see some of the nice benefits from using Sass, so I'll bu sure to practice and learn more.

### Useful resources

- [Sass Basics](https://sass-lang.com/guide/) - Explains the basic concepts and syntax fo Sass.
- [Learn the SCSS (Sass) Basics in 5 Minutes](https://medium.com/swlh/learn-the-scss-sass-basics-in-5-minutes-73002653b443) - Another great resource on Sass. 
This in particular talks about SCSS and I prefer that syntax to genuine Sass. I think it's harder to read the code without the curly braces and semi-colons.
